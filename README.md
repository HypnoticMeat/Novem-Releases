# Novem Releases

Playtest builds of the **Novem Dungeon Player**, a Windows app for playing Novem: a dungeon-crawling sudoku variant.

## Latest: v0.12.2

**[Download NovemPlayer-v0.12.2.zip](releases/v0.12.2/NovemPlayer-v0.12.2.zip)** (35 MB). It contains `NovemPlayer.exe` and `README-Testers.txt`.

1. Unzip, then double-click `NovemPlayer.exe`.
   - Windows may warn that the app is unsigned. Click **More info**, then **Run anyway**.
2. The game opens in your web browser. Keep the small console window open while you play, and close it when you're done.
3. After clearing a puzzle, save a difficulty and fun rating. When you're finished, use **Log → Copy ratings as JSON** and send them back.

See [README-Testers.txt](releases/v0.12.2/README-Testers.txt) for controls, and [CHANGELOG.md](CHANGELOG.md) for what changed in each version.
